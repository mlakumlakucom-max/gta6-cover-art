Neon Coast — an offline web app that turns your photos and a caption into multi-panel GTA-style cover art, exported as PNG in 1080x1080, 1080x1350 and 1920x1080. Six layouts, six sunset/neon grades, OFL lettering, per-panel crop/zoom, undo/redo.

## Run it

```sh
node serve.ts
# Open http://localhost:8080
```
